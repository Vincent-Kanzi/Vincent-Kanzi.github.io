# 01. Agile Team Charter
## OPA Portal Redevelopment

**Organisation:** Cape Peninsula University of Technology  
**Project:** Online Personal Access (OPA)  
**Development Environment:** OPA-Dev  
**Technology:** Laravel, PHP, Filament and MySQL

---

## 1. Project Vision and Mission

The vision of the OPA redevelopment project is to improve the
Online Personal Access Portal by providing a more efficient,
accessible and user-friendly platform for CPUT staff.

The mission is to enhance the existing application through
iterative software development, improved interface design,
structured request management and reliable administrative
processes.

The redevelopment aims to improve how staff interact with
institutional services while maintaining the functionality
and integrity of the existing system.

## 2. Project Objectives

The main objectives are to:

1. Improve the usability and appearance of the OPA Portal.
2. Enhance the staff dashboard and its information widgets.
3. Maintain a unified workflow for staff service requests.
4. Improve the submission and management of VPN, Printing
   Credits and SMS Credits requests.
5. Support administrative review and approval processes.
6. Improve database and email notification functionality.
7. Maintain a structured and maintainable Laravel application.
8. Test changes to reduce the risk of disrupting existing
   functionality.

## 3. Project Scope

The project covers the following areas:

| Area | Description |
|---|---|
| Dashboard | Staff dashboard layout, widgets and activity information. |
| Request Management | Unified management of different staff service requests. |
| VPN Requests | Submission and management of VPN access requests. |
| Printing Credits | Submission and administration of printing credit requests. |
| SMS Credits | Submission and administration of SMS credit requests. |
| Approvals | Review, approval and rejection workflows. |
| Notifications | Database and email notifications for request updates. |
| Administration | Filament-based administrative functionality. |
| User Interface | Layout, branding, navigation and responsiveness. |

The scope is subject to the approved requirements and development
priorities of the project.

## 5. Communication and Collaboration

Effective communication is important because the project involves
improving an existing application.

The team should:

- Communicate changes to shared application functionality.
- Discuss requirements and technical decisions.
- Report defects and unexpected system behaviour.
- Share progress and identify outstanding tasks.
- Review proposed changes before integration where necessary.
- Keep relevant project documentation updated.

## 6. Working Agreements

The following working agreements guide the development process:

1. Existing application functionality must be considered before
   implementing changes.
2. Developers should follow the existing Laravel application
   structure and coding conventions.
3. Git should be used to manage source code and development changes.
4. Changes should be tested before being considered complete.
5. Database changes must be handled carefully.
6. Team members should communicate when modifying shared components.
7. Development tasks should be documented and prioritised.
8. Known issues and incomplete functionality should be reported.
9. Existing production functionality should not be changed without
   appropriate review and authorisation.

## 8. Definition of Done

A task is considered complete when:

- The agreed requirement has been implemented.
- The implementation follows the application's structure.
- Relevant functionality has been tested.
- Existing functionality has not been unintentionally disrupted.
- Any necessary validation and error handling are included.
- The interface has been checked where applicable.
- Changes have been reviewed and documented where required.

## 9. Reflection

The OPA redevelopment demonstrates that improving an existing
application requires more than introducing new features. Developers
must understand existing workflows, database relationships and
dependencies before making changes.

The project highlights the importance of communication, version
control, testing and careful planning. It also reinforces the value
of Agile development, where improvements can be introduced
incrementally and evaluated throughout the development process.
