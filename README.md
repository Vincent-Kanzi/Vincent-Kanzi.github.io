## Featured Project: OPA Portal Redevelopment

**Project:** Online Personal Access (OPA)  
**Organisation:** Cape Peninsula University of Technology  
**Development environment:** OPA-Dev  
**Framework:** Laravel and Filament  
**Database:** MySQL

The OPA redevelopment project focuses on improving an existing
institutional portal used to provide access to staff services and
administrative processes.

The redevelopment includes work on the staff dashboard, request
management, approval workflows, notifications, staff information and
the overall user experience.

### Areas of Development

- **Staff Dashboard:** Improving the dashboard layout and information
  presented to users.
- **Request Management:** Developing a unified workflow for VPN,
  Printing Credits and SMS Credits requests.
- **Approval Processes:** Supporting request review, approval and
  rejection workflows.
- **Notifications:** Working with database and email notifications
  to communicate request status changes.
- **Administration:** Using Filament to manage administrative
  functionality and request information.
- **User Experience:** Improving navigation, layout, consistency
  and responsiveness.

> The project is undergoing redevelopment. The features listed here
> describe the areas of work and should not all be interpreted as
> completed or deployed functionality.
